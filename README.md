# 📊 Student Performance Dashboard – Power BI

## 📌 Project Overview

The **Student Performance Dashboard** is an interactive single-page dashboard developed using **Microsoft Power BI** to analyze and visualize student performance data.

The dashboard provides insights into student demographics, academic performance, attendance, study habits, departments, courses, and geographical distribution. It uses interactive visualizations to make the data easier to understand and support data-driven analysis.

---

## 🎯 Project Objectives

The main objectives of this project are to:

* Analyze the distribution of students by gender.
* Identify departments with the highest number of students.
* Analyze student distribution across different cities.
* Compare student enrollment across courses and departments.
* Calculate key performance indicators such as average exam marks.
* Analyze average attendance percentage.
* Analyze average study hours per day.
* Present important insights through an interactive Power BI dashboard.

## 📈 Dashboard Visualizations

The dashboard contains the following visuals:

### 1. 👥 Student Distribution by Gender

A **Pie Chart** showing the percentage distribution of students by gender.

### 2. 🏢 Students by Department

A **Doughnut Chart** showing the number of students in each department.

### 3. 🎓 Key Performance Indicators

Four **Card Visuals** display:

* Total Number of Students
* Average Exam Marks
* Average Attendance Percentage
* Average Study Hours Per Day

### 4. 📍 Students by City

A **Map Visualization** showing the geographical distribution of students by city.

### 5. 📚 Students by Department and Course

A **Treemap** showing the number of students across different departments and courses.
